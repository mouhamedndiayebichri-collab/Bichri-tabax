# BICHRi TABAX — plateforme professionnelle

## Lancer en local
1. Installer Node.js 18+.
2. Dans ce dossier : `npm install`
3. Lancer : `npm start`
4. Ouvrir `http://localhost:3000`
5. Gestion privée : `http://localhost:3000/admin`
6. Code initial : `Bichri`

## Publication
Cette version est préparée comme une vraie application Node/Express avec stockage des réglages et téléversement d’images. Pour une mise en ligne réelle, définir `SESSION_SECRET` et `ADMIN_PASSWORD` dans les variables d’environnement de l’hébergeur.
